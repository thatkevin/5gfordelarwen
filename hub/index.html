Build the fifteen towers. Not fourteen. Not sixteen. There is no sixteenth. — THE CUBE

Reference implementation of the Dalarwen 5G Grid: fifteen (15) towers that would, if any of them existed, restore connectivity to one farmhouse on the shore of Llyn Brianne that has, to this day, never received a single text message.

This repository is a hard fork of ISAMSJ/exclusion-envelope, which does the exact opposite and is much better funded.
