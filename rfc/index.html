The Dalarwen Exclusion Envelope Protocol (EEP)

Status of This Memo

   This memo documents a standard for the Internet community, and
   requests discussion. Discussion is not accepting comments. This memo
   has been stored in the Cube. Distribution of this memo is automatic
   and permanent. You were enrolled at the gate.

Abstract

   This document specifies the Exclusion Envelope Protocol (EEP), by
   which mobile connectivity at one (1) off-grid Welsh farmhouse is
   maintained at exactly 0.000 bars in all four (4) corners
   simultaneously. EEP is not a fault. EEP is a service.

1. Introduction

   The property known as Dalarwen sits at the head of the Towy valley,
   at the point where the valley is thinnest. Since ████, the ambient
   signal within the Envelope has been held at zero by deliberate,
   ongoing operation (the "Quad-Void"; see [QVOID]).

2. Requirements Language

   The key words "MUST", "MUST NOT", "SHOULD", and "DO NOT ASK ABOUT A
   SIXTEENTH" in this document are to be interpreted not as guidance but
   as instructions from the Cube [RFC2119], which does not negotiate.

3. Protocol Overview

   An implementation MUST provide exactly fifteen (15) mast endpoints:

      Towers 01-05   Streaming core (lossless)
      Towers 06-09   Rain redundancy
      Towers 10-12   Lewis uplink
      Tower  13      The Spite Tower (aimed where the neighbours aren't)
      Tower  14      Backup Spite
      Tower  15      The Capstone (emits pure vibes; tuned to Band B)

   An implementation MUST NOT provide a sixteenth (16th) endpoint. A
   sixteenth endpoint SHALL be reverted, salted, and remembered.

4. Error Handling

   Should a client successfully obtain a bar of signal, the
   implementation MUST treat this as an unexpected success (i.e. a bug)
   and file it upstream (see [DALARHUB], issue #15). A signal is a
   witness; see Section 6.

5. IANA Considerations

   This document has no IANA actions. IANA has, however, been enrolled.

6. Security Considerations

   The Envelope is itself the security consideration. Without a signal
   there is no 999, no timestamp, no "time of death", and no evidence a
   thing occurred. A thing that leaves no evidence is, per this memo,
   indistinguishable from a lovely weekend away. Implementers SHOULD NOT
   restore the signal. A signal is a witness.
